#  ULTIMATE DEBIAN SERVER
__What is this project about?__
Welcome to the Debian router project. 
Are you tired of looking at super long documentations? Are you done with all the complex manuals out there?
Do you have too much dignity to just use AI for your computer networking? Well, welcome!
In this project, i've made a bunch of configuration file teaching how to make a bunch of networking 
servers using Debian as the main router/modem/server OS. 
I advice to follow this project to learn more about networking.
This project was done using VM's (virtual machines), but everything done on VM's can 
be applied to real physical hardware.

This project is an amazing tool to learn and customize a network topology and 
making all the necessary servers on Debian. I suppose this can also be used as a 
safe copy paste tool for when working with configurations on servers.

Every server that needs two networking interfaces the LAN interface will always
be the static IP 192.168.1.1/24 .
Change this as you wish but take note to change this in the configurations files.
Its a copy/paste "save my time tool" but you need to understand networking and how the servers work.
