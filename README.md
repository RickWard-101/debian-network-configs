#  ULTIMATE DEBIAN SERVER
__What is this project about?__

I advice to follow this project to learn more about networking.
This project was done using VM's (virtual machines), but everything done on VM's can 
be applied to real physical hardware.

This project is an amazing tool to learn and customize a network topology and 
making all the necessary servers on Debian. It can be used as a 
safe copy paste tool for when working with configurations on servers.

## Details about the networking
Every server that needs two networking interfaces, the LAN interface will always
be the static IP 192.168.1.1/24 .
Change this IP as you wish but make sure to change it on every configuration file.
